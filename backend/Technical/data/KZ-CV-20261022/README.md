## 建议操作顺序

1. **版本切换与内容隔离**：进入 A，切换 V2、V3、V6，分别应看到 4、5、6 道工序。工序名称包含版本号；加工类别、设备工时、领用量随版本变化。可先编辑 V3，再切换其他版本核对保存行为。
2. **主版本切换与发布**：进入 D，在 V3 暂存版本勾选主版本并保存，再发布；工艺与 BOM 的主版本、状态应一致，同一工艺仅一个主版本。未修改前 V2 是主版本。
3. **废弃恢复/删除**：A-V1、A-V5、B-V4、C-V3、D-V1、F-V1 均为未被工序领用引用的废弃版本，可选择其中一个恢复到暂存再编辑、发布，另选一个验证删除。恢复不应自动抢占主标记。
4. **领用默认主版本**：在 A 的暂存版本中新增壳体半成品 B 的领用行，初始应默认 B-V2，下拉框主版本带圆形“主”标识。B 的已发布选项为 V1、V2；V3 暂存、V4 废弃不应作为已发布选项。
5. **保留已选引用**：A-V1、A-V4 已保存的壳体引用为 B-V1，其余 A 版本引用 B-V2。打开已有记录不应统一覆盖为 B-V2。将 B-V3 设为主并发布后，新加领用行应选择 B-V3，已有引用仍保持原版本。
6. **被引用版本删除**：B-V1 被 A-V1/A-V4 引用。可先取消 B-V1 发布，随后尝试删除，预期提示已被工序物料引用，不能删除。
7. **多级物料**：A → B → C → 原料，同时 A 直接领用 C；所有引用均指向对应产品的已发布工艺版本，无循环。BOM 引用指向对应的 BOM 版本 ID。
8. **用量与替料**：除 E 外，Vn 的主原料在首工序领用 `1.20 + 0.10 × n` Kg、第二工序领用 `0.05 × n` Kg；BOM 应合并为 `1.20 + 0.15 × n` Kg。首工序替料为 `1.35 + 0.10 × n` Kg，包装为 `0.10 × n` 套。例：V2 主原料合计 1.50 Kg、替料 1.55 Kg、包装 0.20 套；产出不计入 BOM，损耗率不额外乘入同步用量。
9. **外协、设备工时**：A/D 的 V3、V4 含外协工序，其上一工序已勾选入库；加工工序配置两台设备，各自工时不同。
10. **发布校验**：E-V1 故意未勾选末工序报工，直接发布应提示末工序条件不满足；补勾选、保存后可发布。其余版本末工序已满足报工及入库条件。
11. **规格换算**：F 的规格为 5米/段，默认产出 1 段对应主单位 5 米；BOM 单位快照包含段与米，可在保存后核对比例及明细用量是否保持一致。

## 宿主字段差异

实际测试库工序表的字段为 `WorkHours`、`IsReport`，设备关联表工时字段为 `WorkHours`。当前工作区实体属性分别为 `TheoreticalWorkHours`、`IsReportWork`，未见对应的列名映射。本批按实际数据库字段写入，没有修改表结构。

如果运行的是当前本地实体，需先对齐实体映射或宿主迁移，否则可能在查询阶段报未知列。生成数据不能代替该字段对齐；运行中的宿主版本尚未核实。
